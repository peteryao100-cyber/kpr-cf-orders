二、一眼看懂核心矛盾：为什么不能再按“所有款 1.5 倍月均”备成品？

痛点诊断与解法对比

❌ 过去做法的三大陷阱（导致 8,154 双积压、主力款却缺货）

  • 陷阱 1：把黄金“共享鞋面”过早注塑成慢销成品！
    805/S (U6700020) 和 026/3 (U2100002) 是 1对4 通用鞋面（同一个鞋面既能打 SP，也能打 EH 和 M8，注塑仅需约 3 天）。但 6–10 月工厂在没有客户订单的情况下，把好鞋面注塑成了 M8（积压 2,549 双）、026/3-EH（积压 2,548 双）、805/S-EH（积压 1,705 双），反而把最畅销的 805/S-SP 饿到只剩 958 双！
  • 陷阱 2：项目脉冲大单严重扭曲“算术月均”！
    例如 L8-026/3-EH 全年 4,122 双销量里，4,045 双（98.1%）是 6 月 COYE 陶总一笔项目大单，平时 9 个月一共只卖了 77 双（月均 8.5 双）。如果机械按“10个月均销 412双 × 1.5”设成品安库，就会常备 600~3,000 双卖不动的 EH 成品。
  • 陷阱 3：成品仓没有“最高水位封顶闸门”！
    6月底 L8-807/8-SP 累计销量为 0，却排产 5,000 双（已入库 1,216 双，至今仅出 3 双样品，1,212 双躺在 IF 仓）。

✅ 新方案：【二级解耦安库模型】（重上游共享鞋面池 · 轻下游慢销成品）

  • 第一级（上游）：在 IF 设立【共享鞋面安全库存池（3个月 = 8,900双）】
    因为鞋面采购前置期长达 2 个月，而鞋面在 IF 上机注塑成成品仅需 约 3 天。把安全缓冲留在通用的 U6700020 (805/S) 和 U2100002 (026/3) 鞋面上，不管是金牛日常补单还是 COYE 突发大单，都能随时调拨注塑！
  • 第二级（下游）：IF 成品按 A / B / C 三级严控水位（总目标 4,750 双）
    • A 类（2款主力 SP）：占销量 85.4%，设常备成品安库（805/S-SP 目标 2,000双、026/3-SP 目标 1,850双），满足日常秒发。
    • B 类（3款脉冲/专案 EH & 807）：只设小额样品/底线缓冲（合计 900双），大单来了直接从第一级“共享鞋面池”领料 3 天注塑！当前超储的 4,565 双 立即锁死排产、优先清库。
    • C 类（11款 M8 及样品）：成品安库一律设为 0 双（100% 凭正式锁单生产 MTO），全力消化现有 2,689 双 死库存。
