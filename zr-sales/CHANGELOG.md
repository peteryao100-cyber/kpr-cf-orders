### 页面特性
- **全页面筛选驱动**：顶部筛选栏（时段、单元、客户、款式、渠道、品牌）控制页面所有 KPI、图表、表格
- 时段选项：
  - 2026 同期（1月上旬–11月上旬，仅完整旬）
  - 2025 同期 / 2024 同期
  - 2025 全年 / 2024 全年
  - 2026 截至 11-15
  - 同期对比（三年同期并列）
  - 全部数据
- 单元选项：
  - 成品鞋合计（内销+外销+绿安全国内+绿安全外贸+X）
  - 内销 / 外销
  - 绿安全国内（华南/华东/华北）/ 绿安全外贸
  - X / OEM鞋面/半成品 / 钢头 / 橡胶底 / 3M / 材料 / 鞋垫 / 其它劳保 / 其它未标品牌
  - 全部单元

- 绿安全国内（2026 同期）：**41,220 双**（不含 30 件鞋垫） ✓

### 技术实现
- Python 构建脚本 (`build.py`)：加载 Excel、合并数据、应用汇率、分类行、生成 HTML
- 整数分（fen）计算避免浮点误差
- 行分类逻辑：
  - 内销：品牌=尊荣 且 渠道=外贸 以外
  - 外销：品牌=尊荣 且 渠道=外贸
  - 绿安全国内：typ=内销/MIDORI 按区域分华南/华东/华北
  - 绿安全外贸：typ=外贸/EXPORT
  - X：typ=X 客户
  - 其他单元按 typ 字段判断
- `is_shoe` 标记：绿安全名下鞋垫标记为 `is_shoe=False`，金额计入但不计入成品鞋数量
- 13 行空币种行：数量计入，金额不计（标注"未计营业额"）

### 输出文件
- `zr-full-sales-v4.html`：自包含单页面，无 CDN 依赖，嵌入全部数据与 JavaScript
