目的：IF/MSL 安库每日闭环所需 Open API / ERP 接口清单，方便 IT（Doris）排期开/改接口。 优先保证能每日拉数。安库业务规则以 Boss 已确认口径为准；接口只负责供数，不代替水位决策。
重要口径（Boss 11/6，Doris 勿按旧缺项开多余接口）：
  • 先确认规则，再接每日接口（本表明细仍请现在排期）。
  • 赠品/退货：并入每日流水，用订单类型/发货类型区分；不再单列缺项。
  • 6-2：不要单独「安全库存单完成表」；WIP=已发鞋面未射出 + 已下线未入库；已发鞋面与排产占用只计一次。

  • 6-4：入库流水仅对账，不挡水位。
  • 印度鞋面不良：规则参数按实际 12–15%（保守 15%）；QC 流水为 P2 可选，非阻塞。
